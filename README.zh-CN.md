# 薄雾设置（mist-enhancer）

「薄雾」思源笔记主题的可视化设置插件。**只在薄雾主题下生效**，切到别的主题时插件写入的一切会自动撤销。

## 它管什么，不管什么

| 能力 | 归属 |
|---|---|
| 去框、磨砂、右侧玻璃悬浮条、面包屑透明、顶栏分割线 | `theme.css`（不装插件也完整） |
| 区域颜色与透明度、背景图、字体字号、文档树图标、对比度 | 本插件（需要面板 + 记忆） |

一句话：**主题是皮肤，插件是遥控器。** 遥控器拿掉，皮肤不能烂。

## 功能

0. **设置页开在右侧停靠栏**（0.2.2 起）— 点顶栏图标或右侧栏的薄雾图标，面板出现在右栏，编辑器留在左边，改一个数值当场就能看到效果。面板宽度可拖动（默认 348px，拖过会被记住）。移动端或找不到停靠项时自动退回居中弹窗。
1. **颜色与透明度** — 目录+左停靠栏、编辑区+标签页、顶部工具栏、右侧玻璃面板，四组各自独立调颜色与透明度。透明度 100% 为实色，0% 完全透出背后的图。
   点色块会**在那一行下面就地展开取色器**（饱和度方块 + 色相条 + hex 手输 + 吸管），不再拉起系统取色面板。
   **一键套用 5 套**（0.2.28）：雾 / 清透 / 纸感 / 仿 wolai / 夜雾。预设会同时写入浅色与暗色两套值，套完仍可继续微调。带强调色的预设（如仿 wolai 的珊瑚红）会连思源原生主色 `--b3-theme-primary` 一起换，按钮/标签页/链接不会「一半红一半蓝」；「仿 wolai」还会把区域分割线（顶栏下 / 侧栏右 / 右面板左）一并设为透明。
2. **背景图** — 上传自己的图作为笔记背景。支持整个界面（含顶栏、侧边栏）或仅编辑区两种作用范围；填充铺满 / 完整显示 / 平铺，三档位置。上传的图自动压到 1920px 宽并转 JPEG，避免设置文件膨胀。（0.2.1 移除了内置预设图，只保留自上传。）
3. **字体字号** — 正文字体与字号、文档树字体与字号、文档标题独立字号（与正文解耦）。
4. **文档树图标** — 从**当前启用的思源图标包**里选笔记本与文档的默认图标，可搜索。只替换没单独设过图标的条目；你自己换过图标的文档保持原样。
5. **全局对比度** — 0–100，50 为主题默认。调低文字往背景色靠，调高往纯黑/纯白靠。只动文字，不动背景。
6. **明暗两套值** — 浅色和暗色各存一套，面板顶部可切换编辑目标。
7. **浮动面板**（0.2.9 起）— 浮动布局下侧边面板的玻璃外观：圆角、模糊、饱和度、不透明度、阴影、外间距、磨砂颗粒，外加 6 种弹出动画（方案 / 时长 / 缓动曲线都可配，点「播放一次」当场预览）。左侧文档树、右侧面板同样适用。
8. **标题栏图钉**（0.2.10 起）— 浮动面板的标题栏右端放一个图钉：点一下把**这一次的浮出状态锁住**，鼠标移开也不再收起（方便一边调参数一边盯着面板），再点一下松钉恢复「移开即收」。布局**仍然是浮动**，玻璃外观不变。

## 几个实现上的关键决定

**图标不打包。** 思源的图标包 `icon.js` 本质是一句
`document.body.insertAdjacentHTML(...)`，把 `<svg id="iconsXxx"><defs><symbol id="iconYyy">`
插进页面。当前启用的包在页面里已经存在，插件直接
`document.querySelectorAll('svg[id^="icons"] symbol')` 枚举即可 —— **插件体积不因图标变胖**。
本机 6 个图标包合计 927 KB，全部打包进来毫无必要。

**文档树图标不靠 CSS。** 思源的「换图标」入口挂在 `.b3-list-item__icon` 上，用 CSS 覆盖这个类会让右键换图标直接失效（薄雾主题 0.2.12 踩过）。本插件的判据：

- 带 `aria-label` 的图标 span = 用户自定义过 → 一律跳过
- 否则看 `svg > use` 的 href，只有属于思源默认四件套
  （`iconNotebook` / `iconFileText` / `iconFile` / `iconLock`）时才替换

替换只改 `use` 的 href，不动 span 的结构、aria 属性与点击热区。原值记在 `data-mist-orig` 上，
所以换图标、改配置都能正确还原。

**两个 render 方法不能同名。** 0.2.0 里外观预设与背景图格子都叫 `renderPresets`，
后定义的那个把前者整个覆盖掉 —— 表现就是「一键套用」那一行永远空白，控制台没有任何报错。
现拆成 `renderLookPresets`（外观四套）一个入口。写 JS 时同名方法不报错、静默覆盖，这类 bug 只能靠断言兜住。

**图钉钉的是「这一次浮出来」，不是布局。** 思源自己的 pin（`dock.togglePin()`）会把浮动布局
切成固定布局，玻璃效果整套随之消失 —— 那不是我们要的。这里的图钉只管用 CSS 把面板钉在
展开态：

- 思源收起面板 = 改 inline 的 `transform`（推回负位移）+ `opacity` 归 0；
- 作者样式表里的 `!important` 压得住 inline 的普通值 —— 所以锁定期间在 `<html>` 上打
  `data-mist-lock-l`，CSS 就用 `!important` 把这两个值钉在展开时的数值上；
- 不轮询、不拦事件、不改 DOM：思源照写它的 inline，只是写了不生效，松钉的瞬间立即恢复。

展开位移按**图标栏实际宽度**算（`translateX(34px)`），不抄 `el.style.transform`：那个值是
「此刻」的位移，若此刻刚好是收起态（`-278px`），照抄就把面板锁到屏幕外去了（0.2.10 首版踩过）。

**只写变量，不改 DOM。** 所有视觉参数以 CSS 自定义属性的形式内联写到 `<html>`，
主题的 `theme.css` 提供默认值。插件不搬节点、不改结构 —— 薄雾 0.2.13 那次右栏塌高的教训。
